# 整图与已有贴图拆件

用于制作 Spine 动画时，将完整 PNG/JPG、合并图层或现有附件进一步拆成可独立运动的部位。先读取 [通用 Photoshop](photoshop.md) 和 [游戏 Spine 切图](game-spine-slice.md)；需要补齐遮挡区域时再读取 [Spine 自动补图](spine-image-repair.md)。

## 根据动作确定拆分

单张完整图片制作 Spine 动画时，拆图是必经步骤，包括 idle、小幅呼吸和摆动。先得到按运动与遮挡关系分离的真实部件图层/透明 PNG，再进行绑定和动作制作。不能将完整角色图直接作为单个 region/mesh，也不能把整图的多骨骼权重分区或 FFD 称为拆件。各部件可进入同一图集，但必须保有独立纹理区域与附件关系；仅复制整图、矩形分块或重复挂接整图不算拆件。

只有扁平角色图、缺少遮挡区像素或需要语义分层初稿时，按需读取 [See-through 单图分层与 Spine 衔接](../references/spine/see-through.md)，评估可选外部推理后端。模型输出先作为候选 PSD，再按本模块拆成实际运动部件；环境未就绪时沿用现有 Photoshop 工作流，不宣称已启用 AI 拆件。

- 先查看原图和目标动作；已有工程同时检查附件、骨骼、网格、权重、FFD 与遮挡顺序。只有需要独立旋转、形变、换图或前后遮挡的区域才拆分，不默认把整个角色细碎化。
- 例如挥手可能需要上臂、前臂和手，头发摆动可能需要前后发与发束，眨眼可能需要眼部替换件。已经拆出的单个运动部件可保留为一片并使用网格形变，不要求将其继续细碎拆分。
- 部件划分依据目标姿势：胸肩、头部、手臂和衣发需要不同运动、遮挡或替换时，分别拆件并恢复遮挡区。不能因为整图能做小幅起伏就跳过拆图，也不能为避免拆图而缩小用户要求的幅度。
- 记录部件名称、源区域、接缝、拟定关节、前后关系和会暴露的缺画；左右沿用已有工程约定。没有动作说明时按可见结构做保守拆分，说明活动范围尚未验证。

## 分离可见像素与补齐遮挡

1. 保留原图，在工作 PSD 副本中按原尺寸建立部件层，以路径、选区或蒙版沿实际轮廓分离。矩形裁切只用于最终导出，不能将背景或邻近肢体一起当作部件。保留发丝与半透明边缘，检查背景色污染。
2. 同一张图可以提供多个部件的可见像素，但遮住的内容并不存在于扁平图中。移动手臂后露出的躯干、移开刘海后的额头、拆出眼睛后的脸底等，需要恢复可用源或补绘；不能把背景透明洞当作完整部件。
3. 动画所需的关节搭接与遮挡补全纳入拆件工作，按补图模块执行。局部缺口优先保留适用的原像素，仅合回所需补绘区域；若目标姿势需要完整的新轮廓，或旧片叠回后形成双轮廓/破坏关节体积，比较后可采用完整的目标部件，核对身份、线条、材质、光照、配准和邻接关系，记录替换范围。不要为了保留原像素而叠出两条肢体，也不通过生成整套新角色替换原稿。用户要求仅提取原像素时尊重该限制，缺画记为 `needs_redraw`。
4. 若使用生成式编辑，先检查参考图并使用当前可用图像编辑工具，按其技能与参数执行；结果须配准、蒙版合成并验证真实 Alpha。工具不可用时交付已完成部分和缺画清单，不宣称完整可动画化。
5. 按实际转轴和目标角度检查肩、肘、膝、颈与发根的搭接。透明 padding 不能替代实体像素；大角度转身或全新手势需明确为补绘设计或替换件。

## 活动遮挡下的部件完整性

适用于翅膀覆盖腹部、袖片覆盖手臂、刘海覆盖额头等前后件存在相对运动的拆件。进入绑定前，按目标动作执行以下检查。

1. **核对像素归属。** 分别只显示主体、前件和后件，检查胸腹、条纹、肢体或工具轮廓是否留在所属部件。多边形选区、颜色阈值和连通域用于产生候选边界，归属由实际结构、透明边缘及遮挡关系决定。检查翼膜、布料等部件时同时保留适用的轮廓与半透明笔触。
2. **移开遮挡件检查底层。** 隐藏或沿实际枢轴移开遮挡件，查看主体的轮廓、体积、末端和连接。区分设计透空与缺画，恢复范围以目标动作会暴露的区域为准。静态互补蒙版只分配了已有可见像素，活动后露出的底层需另行恢复。按实际运动保留有像素的前后搭接。
3. **完成恢复后复验。** 将能从原稿或适用同类部件恢复的像素配准到缺口，比较比例、纹理方向、条纹节奏、光照和外轮廓。记录供体区域、变换和采用范围，再装回遮挡件检查展开、收拢及中间过程。同类部件复用依据来自当前素材，按角色逐项判断。
4. **覆盖同批实例。** 多只昆虫、多个果实或同一方法批量拆出的部件，按稳定编号逐件隔离检查。某件出现误归属或缺画时，扩查使用相同选区、脚本或恢复方法的同批部件，并记录逐件结果。

素材交接证据包含原图局部、移开遮挡件后的主体、独立遮挡件及代表性极值合成。原位重建差异用于检查摆位和已有像素覆盖，遮挡完整性依据上述隔离画面与动作试摆分别判定。按需使用 [Spine 自动补图](spine-image-repair.md) 执行恢复，进入真实动画后按 [逐件与局部周期审查](../../spine-skill/modules/delivery.md#逐件与局部周期审查) 复验。

## 语义分层候选的完整性

使用生成分层或爆炸图时，先逐层隔离，再按原位重合成：双手与衣身、持物与手指、前后发及动作需要的衣片是否实际分离，各自被遮住的部分是否完整。中间残留整个人、按阴影/色块分层、漏掉服饰或将手与武器粘成一片，均不是可直接绑定的结果；提高分辨率或超分不能补救缺层和错误语义。

按原推理的裁切、补边和缩放关系还原统一画布，检查单层 Alpha 和实际可见边缘；深度仅辅助同一次结果的层序，不能混用不同次推理的深度值。源恢复件与完整生成替换件分别记录采用方式，避免未经配准混贴。合成差异、轮廓覆盖和像素指标用于定位缺片/漂移，阈值按当前画风与显示尺寸确定，不照搬其他角色的 IoU 或误差常数。完整部件和原位重建通过后，再做目标姿势试摆。

## 原位与已有动画兼容

- 在统一整稿坐标中操作，保留部件的原位、比例和前后顺序。沿用切图模块的 `export_box`、原点、透明边与 PNG 约定，不能逐件居中后丢失位置。
- 扁平图来源用原始图片路径及区域/蒙版标识记录；工作 PSD 的真实图层 ID 可另记，不能伪造原稿已有图层。清单记录哪些像素来自原图、哪些属于补绘。
- 新部件需同时显示时建立独立 slot；互斥表情或手势使用附件切换。拆件不能只替换图片文件：已绑定附件拆分后，在工程副本中重新处理枢轴、附件变换、网格 UV、权重和相关 FFD，并检查原附件的显示关键帧，防止新旧部件重复显示。
- 已有贴图被多个 skin、附件或动画复用时，检查全部引用；只修改目标范围。保留原纹理和工程的可恢复版本，不能假定旧网格与紧裁后的新 PNG 兼容。

## 交付与复验

- 绑定前核对拆件联系表与附件映射，确认导出的确为独立部位而非重复整图，并按原位重建确认角色完整。若工具或素材条件导致拆图未完成，明确报告未完成项，不回退为整图动画交付。

- 沿用 Spine 切图的任务目录，交付透明部件 PNG、坐标清单、可编辑工作 PSD、原位重建和拆件联系表。已有工程另记录旧附件到新部件的映射及待更新的绑定/动画。
- 按坐标和 draw order 重建基准姿态，与原图比较，检查漏片、重影、接缝、白边和意外改变；补绘区另做可见性检查。
- 在目标 Spine 动作中检查代表性极限姿态与整段播放。没有骨架时可做关节试转，但只能标为近似检查；静态重建通过不等于动画通过。
- 用户请求制作动画时，拆件完成后返回 [Spine 技能](../../spine-skill/SKILL.md) 继续绑定、动画与验收，不在导出 PNG 后结束任务。
