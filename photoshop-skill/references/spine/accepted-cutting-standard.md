# 已验收人工工程：Spine 切图标准

本页从用户于 2026-10-23 确认已通过验收的 `XiaoGuan/art/spine` 工程与实际 PNG 提炼切图要求，服务于同类角色制作。工程范围、版本、证据和样本限制见 [人工工程制作与验收标准](../../../spine-skill/references/accepted-production-standard.md)。本次直接检查了输出 PNG、附件映射、网格与时间轴，没有读取对应源 PSD；因此不把推定的分层或补绘方法描述为原作者实际操作记录。

上述是动作职责的示例，不是每个角色必须照抄的文件清单。单个可动件可以合并自身的颜色、线稿和阴影；独立运动、不同层次或互斥状态才分别处理。要点是目标动作能成立，而非切得越碎越好。

## 补全、Alpha 与画布

- **实体搭接按目标活动范围检查。** 肩、肘、颈、腰、膝及发根在旋转后仍有可用像素，遮挡物移开后能显示合理底层。透明边只解决裁切与采样边界，不能替代关节和被遮挡区域的实体内容。输出件的圆滑端头可作搭接参考，但是否足够仍由实际试姿确定。
- **区分设计透明与缺画。** 女主和书生的脸底在眼部有透明区域，由眼白、瞳孔和眼线组合；这类透明不能机械填成肤色。单件检查结合 slot、遮罩/层次与组合效果，目标姿势中意外露出背景才是需修复的问题。
- **保留真实轮廓。** 透明 PNG 保留半透明边缘、线条、纹理与光照，独立查看时不应带出相邻肢体或原背景。用棋盘格和明暗背景检查边缘，不能只看一张整角色合成。
- **沿用已有画布。** 实测书童 83、农夫 61、官家小姐 76、绣娘 96、账房 69 张被引用的源 PNG 均为四边 1 px 透明边；其他工程还存在无透明边或不对称留白。它们已进入绑定，不为了统一 padding 重新裁边、居中或补边。新资源仍采用 [切图模块](../../modules/game-spine-slice.md) 的默认 2 px，目标项目另有约定时从其约定；两者都不构成对历史资产的质量否决。
- **替换件不要求相同尺寸。** 女主右手 `CS_youshou` 为 61 × 98，`BP_youshou` 为 77 × 82，`DP_youshou` 为 107 × 63，`KX_youshou` 为 100 × 93；通过附件变换、骨骼及各自的网格表达不同手势。新替换件应记录各自坐标与锚点；更换旧 mesh 图片时必须检查旧画布、UV 和 FFD，不能只按图片中心对齐。

## 附件、命名与资源覆盖

1. 同时显示的五官、前后衣片和左右部件需要独立 slot；同一位置的互斥手势或嘴型可以是同 slot 多附件。大幅度动作也可以使用独立 slot 和专用骨链，但须有完整的显示/隐藏切换。
2. 部件、附件、纹理和骨骼不是一一对应。女主 `女主_xin` 的 123 个附件引用 89 个纹理路径；界面星星也有多个插槽复用同一纹理。统计先跟踪实际 path 与引用关系，不把重复使用当作漏切，也不为每根骨骼复制图片。
3. 保留现有大小写与拼写，建立部位—状态—slot—attachment—图片映射，不猜 `BP / DP / bq* / bt04` 的业务含义。新命名遵循现有技能的稳定命名规则，不照搬历史中的普通数字名、错拼或“图层”名称作为新规范。
4. 源图目录可含未引用的参考图或旧件，书生样本就有背景及初始动作图片。已有工程不据此批量删除；新交付时区分实际角色资源、参考与排除项，默认不把背景和参考整图装进角色附件或交付图集。
5. 按真实图片目录解析引用，不强制名为 `images/`；Tick 的源目录实际为 `image/`。重新打包时跟踪全部 atlas 页面，打包页中的旋转和裁边偏移不等同于源部件裁切信息。

## 切图验收

切图的素材验收与 Spine 动作验收分别记录。素材通过表示部件和定位可用；活动范围通过才表示它能支持对应动画。

| 检查项 | 通过标准 | 检查产物 |
| --- | --- | --- |
| 覆盖与切分 | 基础部件、所需表情/手势/动作替换件齐全；独立件没有夹带整角色或相邻部位 | 源稿覆盖清单、按部位与状态排列的拆件联系表 |
| 原位与外观 | 按坐标和层次能恢复基准角色，比例、颜色、边缘与原稿一致；补绘区单独标识 | 原位重建与原稿对照，不逐件自动居中 |
| 关节与遮挡 | 目标姿势中无意外背景洞、断缝、前后错误或多套肢体同时显示 | 肩肘膝颈等代表极限姿势及层次交换帧 |
| 替换连续性 | 手势、嘴型、袖型切换锚点合理，必要的可见性与顺序关系已说明 | 替换件映射、换图时刻及邻帧预览 |
| PNG 与引用 | 文件可解码、Alpha 和真实尺寸正确，名称及 path 对得上；旧绑定兼容范围明确 | PNG 尺寸/Alpha 检查、引用校验及兼容说明 |
| 下游验证 | 已在目标绑定和动作中确认活动范围；未执行时如实记录待验证 | 工程/动画名、时间或帧号、实际查看的预览 |

本次已有工程未提供制作时的原位清单、源 PSD 或补图历史，不能由输出 PNG 反推出这些记录已存在。新任务仍按 [交付数据约定](delivery.md) 生成可追踪的 PNG、坐标、替换关系和验证记录，不把历史流程缺少清单解释为新任务可以省略定位证据。
