# art-mcp-skills

面向美术工作流的 MCP 与技能集合，覆盖动作剧本与制作规划、Photoshop 素材处理、游戏 UI / Spine 部件切图和 Spine 角色动画制作。

| MCP / Skill | 功能 | 详细文档 |
| --- | --- | --- |
| [Spine MCP](spine-mcp/README.md) | 读取、编辑、预览和导出 Spine 工程 | [用户手册](spine-mcp/docs/USER_MANUAL.md) |
| [Spine Skill](spine-skill/README.md) | 骨架装配、权重绑定、约束与动画制作 | [安装与使用](spine-skill/references/getting-started.md) |
| [Photoshop Skill](photoshop-skill/README.md) | Photoshop 编辑、游戏 UI 切图与 Spine 部件导出 | [安装与使用](photoshop-skill/references/getting-started.md) |
| [Spine 动画导演](spine-animation-director/SKILL.md) | 根据 PSD / 单图编写动作剧本、制作规范与切图补图蓝图，并统筹完整制作 | [安装与使用](spine-animation-director/references/getting-started.md) |

各组件衔接完成从美术源稿、动作设计、切图补图到 Spine 角色动画的制作流程。
