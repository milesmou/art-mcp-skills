# 默认交互预览

用户已于 2026-10-30 选择交互预览并要求不生成 GIF。本流程覆盖参考、制作前方案和成品，默认不编码 GIF，也不为播放器先生成 GIF 再解码；只有用户明确要求 GIF 时另行导出。已有历史 GIF 不自动删除或重写，新的默认页面使用交互播放。

## 播放来源

- **制作前方案**：用独立关节/轮廓模型按时间绘制，或从原始绘制直接导出无损 PNG 帧/分帧图集。不要先拆件或创建正式 Spine 动画来充当方案；主要行为必须在预演中可见。
- **已验收参考与现有动画**：从真实工程的只读快照、实际图集与对应版本 Spine runtime 播放/渲染。帧播放器也可审阅，清楚标注它是预渲染画面，不能称为实时骨骼动画。
- **正式成品**：优先按目标版本使用 Spine runtime 检查实际骨骼、网格、换图与层次；无损帧播放器用于回看和对照。运行时行为仍按项目交付范围验证，不能用预渲染画面代替混合/事件检查。

## 无损帧播放器模板

复用 [交互播放器 HTML](../assets/interactive-preview.html)，复制到任务预览目录，命名 `index.html`。同目录准备 `frames.json` 与 PNG 帧图集。图集每格是完整、相同取景的画面，按行从左到右、再由上到下排列；多个页面按 `sheets` 顺序续排。

```json
{
  "title": "角色 · idle · 方案 v1",
  "description": "左侧源图参考，右侧关节预演。",
  "status": "方案待确认",
  "scope": "独立关节预演，尚未制作正式素材和 Spine 工程。",
  "motion_note": "填写本方案可观察的主要行为。",
  "width": 760,
  "height": 750,
  "fps": 25,
  "duration": 3.2,
  "count": 80,
  "columns": 4,
  "perSheet": 16,
  "sheets": ["frames/sheet-00.png", "frames/sheet-01.png", "frames/sheet-02.png", "frames/sheet-03.png", "frames/sheet-04.png"],
  "beats": [{"time": 0, "label": "P01 起始"}, {"time": 1.2, "label": "P02 接触"}]
}
```

尺寸、帧数、节拍和时长是格式示例，不是动作规格；`beats` 采用真实关键姿势，`blueprint` 可选且为本页相对路径。`scope` 指明参考/代理/成品与播放方式，不把静态参考面板说成当前角色已完成。动画原始帧率、工程 FPS 与播放器采样帧率分开记录；循环采样通常取 `[0,duration)`，结束状态另验，不为拼接多加一帧停顿。

通过绑定本机回环地址的静态服务打开页面，例如从项目根目录执行 `python -m http.server <端口> --bind 127.0.0.1 --directory <本任务预览目录>`，或复用既有服务。后台启动遵循当前环境约定。不要假设双击 `file://` 能读取 JSON；给用户实际可打开的预览 URL，保留页面与数据以便重开服务。

## 控制与验证

默认提供播放/暂停、上一/下一帧、0.25×/0.5×/1×速度、时间轴、关键姿势定位和缩放；用户选择速度只影响播放，不改源时间轴或正式工程。不同方案对比时用相同显示高度和正常速度。

打开实际页面，检查资源加载、正常速度循环、暂停、逐帧、时间轴、速度选择、关键接触点及缩放；至少核对一次准确帧号/时间跳转。保存观察条件与版本，不以 JS 无报错或首尾数值相同代替画面验收。模板只负责播放，源帧、参考匹配与动作质量由制作流程验证。

需要与参考并排时为每个片段准备独立页面，或扩展同一播放器的对照布局；不要把参考 GIF 作为新预览管线的必需输出。工具暂不可用时交代缺项并修复，不自动回退生成 GIF。

## 确认与交付

用户明确通过的是该版本动作方案；选择这种预览方式、调速或拖动时间轴不等于同意动作。正式制作依照 [Spine 交互预览验收](../../spine-skill/modules/animation.md#制作前交互预览与用户验收)，不因格式变化跳过确认，也不重新要求用户审批已通过的同一范围。

交付保留 HTML、元数据、帧图集或运行时资源与实际预览链接。分享视频或 GIF 仅在用户需要时导出，不把额外编码作为验收的默认步骤。
