# Spine MCP

[Project home](../README.md) · [中文](README.md)

An MCP server for Spine 3.8 Professional with 85 tools for project inspection, skeleton and animation editing, meshes and weights, atlas packing, previews, and exports.

- [User manual](docs/USER_MANUAL.en.md): requirements, installation, client configuration, and tool usage.
- [External tools (Chinese)](docs/EXTERNAL_TOOLS.md): official atlas packing, automatic meshes, and libigl weights.
- [Daily editing (Chinese)](docs/DAILY_OPERATIONS.md): weights, cloth, FFD, events, and animation ranges.
- [Headless editing (Chinese)](docs/HEADLESS_EDITING.md): transactions, project rebuilds, and save validation.
- [Version support (Chinese)](docs/VERSION_ARCHITECTURE.md): Spine 3.8 support and future adapters.

Integrated from [spine-mcp-server](https://github.com/milesmou/spine-mcp-server). MIT license.
