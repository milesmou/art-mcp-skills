# Spine MCP

[项目首页](../README.md) · [English](README.en.md)

基于 MCP 的 Spine 3.8 Professional 服务，提供 85 个工具，支持工程读取、骨架与动画编辑、网格和权重处理、图集打包、预览与导出。

- [用户手册](docs/USER_MANUAL.md)：环境要求、安装、客户端配置与工具用法。
- [外部工具](docs/EXTERNAL_TOOLS.md)：官方图集打包、自动网格与 libigl 自动权重。
- [日常编辑](docs/DAILY_OPERATIONS.md)：权重、布料、FFD、事件与动画片段。
- [后台编辑](docs/HEADLESS_EDITING.md)：编辑事务、工程重建与保存校验。
- [版本支持](docs/VERSION_ARCHITECTURE.md)：3.8 支持范围与后续适配设计。

源码整合自 [spine-mcp-server](https://github.com/milesmou/spine-mcp-server)，采用 MIT 许可。
