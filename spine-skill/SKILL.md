# Spine

这是 Spine 功能的统一技能入口，依赖 `spine-mcp`。根据用户目标读取下列模块；模块是内部参考文档，不单独注册、安装或调用。

从 PSD/单图与动作要求开始的完整制作，先由 [Spine 动画导演](../spine-animation-director/SKILL.md) 编写动作剧本、制作规范和切图补图蓝图，再回到本技能绑定与制作。已有导演方案时沿用其版本、姿势标识及已通过的交互预览，不重新启动规划；已有工程局部编辑直接使用本技能。

## 按任务读取

| 用户目标 | 需要读取的模块 |
| --- | --- |
| 读取工程、查询版本与能力、检查层级或分析资源 | [工程通用](modules/project.md) |
| 从拆分贴图装配骨架，修改枢轴、权重或 IK 绑定 | [工程通用](modules/project.md) + [骨架绑定](modules/rigging.md) |
| 创建或修改动作、关键帧、表情、换图、FFD 和衣料跟随 | [工程通用](modules/project.md) + [动画制作](modules/animation.md) |
| 评估动作质量、验收画面与循环、导出运行时资源、处理预览或恢复问题 | [工程通用](modules/project.md) + [预览交付](modules/delivery.md) |
| 修复穿帮、关节露底或动作生硬，配合补图改善动画效果 | [工程通用](modules/project.md) + [动画制作](modules/animation.md) + [防穿帮与动作优化](modules/motion-quality.md) |
| 从单张完整图片制作动画，或进一步拆分已有附件 | 工程通用 + 骨架绑定 + 动画制作，并衔接 [Photoshop 整图与已有贴图拆件](../photoshop-skill/modules/image-part-split.md)；单图输入必须先拆件 |

- 仅加载本次任务所需模块；已读内容不重复读取。跨绑定、动画与导出的完整任务按阶段补读对应模块。
- **先审查，再交付预览**：新制或修改版交给用户前，执行 [预览交付前审查](modules/delivery.md#预览交付前审查)，检查穿帮、动作合理性、接触与循环，记录结论；明显问题先修复并复审。正常播放和实际贴图的画面审查不能由导出成功、数值检查或“待用户验收”替代。
- **先验收交互预览，再制作动画**：制作或调整 Spine 动画前，按 [制作前交互预览与用户验收](modules/animation.md#制作前交互预览与用户验收) 提供支持暂停、逐帧、慢放和时间轴的交互预览；默认不生成 GIF，仅用户明确要求时导出。用户明确验收通过后，才开始正式拆件、绑定和动画编辑。未通过时只迭代预览方案；已明确通过的同一版本与范围不重复申请验收。制作后的成品检查仍须完成。
- 每次写入都执行工程通用模块的保存与回读检查；制作或修改动画后，按预览交付模块的动画验收标准检查，按需求完成预览或运行时资源交付。
- 新动作或整体质量优化按动画制作模块的分阶段流程推进，主体姿势和运动通过视觉检查后再添加附属运动；待机、攻击和走跑按需读取动作配方。局部修改只复查受影响阶段，不强制重做整个动作。
- 制作同类角色、改善表现或确定质量基线时，读取 [已验收人工工程标准](references/accepted-production-standard.md)，按体型、用途和状态选参考；其中样本数量、时长、骨骼数和运动幅度不作为通用门槛。
- 动画制作包含目标姿态的缺画检查和动作自然度调整；发现像素缺失时按优化模块与 Photoshop 补图流程协作，再回到同一姿态复验。MCP 模板生成、自动权重或布料工具成功不代表画面无穿帮。
- **单张完整图片制作 Spine 动画必须先拆图**：按运动与遮挡关系分离为实际部件，补齐必要遮挡区和关节搭接，再建立 slot、枢轴、网格、权重及动画。不允许直接将完整角色图作为单个 region/mesh 制作动画；增加骨骼、权重分区或 FFD 不算完成拆图，idle 和小幅动作也不例外。网格与 FFD 用于拆分后的部件。拆件导出后继续完成用户要求的动画。
- 编辑目标以用户指定路径为准。引用参考工程表示借鉴方法，不自动将参考工程作为编辑目标。
- 延续女主绑定或动作时，按需读取 [mainGirl1 参考](references/main-girl.md)；该工程的骨骼名和参数不作为其他角色的默认值。
- 具体 MCP 参数与示例见 [操作工作流](references/mcp-workflows.md)，仅查阅当前操作的相关段落。工具支持范围以当前连接的 schema 和能力查询结果为准。
- `scripts/inspect_spine_json.py` 只读导出的 JSON，不直接解析或修改二进制 `.spine`。写出候选 JSON 或 dry-run 成功均不代表已保存工程。

## 调用示例

- `使用 $spine-skill，检查 D:/art/hero.spine 的版本、骨架和现有动画。`
- `使用 $spine-skill，将已拆分角色 PNG 装配为骨架，检查枢轴、层次、网格权重和 IK。`
- `使用 $spine-skill，在现有 idle 基础上制作呼吸循环，保留原动作并导出预览。`
