# 预览、交付与恢复

先读取 [工程通用](project.md)。使用当前保存后重新导出的快照，避免用旧 JSON 或旧 `.skel` 验证新动作。

## 引用与画面检查

1. 运行 `spine_validate_references` 并回读目标对象，检查工程保存、动画名、时长和受影响轨道。
2. 显式提供 `atlasPath` 与 `imagePath`，用 `spine_render_preview(mode="sequence")` 查看整段姿势与层次，并检查返回的 `renderer`。当前实现实际要求图集和图片，不能仅依赖工具描述中的无图集回退。
3. 线框用于检查骨骼、枢轴与权重跟随，纯画面用于检查穿插、边缘、形变和层次。静态序列检查姿势，连续播放检查速度、滞后与接缝。
4. sequence 的 n 帧采样为 `duration*i/n`，不含精确终点。另检查 `0`、`duration-ε` 和结束状态；渲染器可能在 duration 时自动循环，原始端点与非循环播放也要检查。
5. 单帧预览优先显式传 `time`，避免预览默认 FPS 与工程帧率不同。没有导出宽高元数据时显式提供预览尺寸。

完整预览参数见 [操作工作流](../references/mcp-workflows.md) 的“预览、导出与恢复”。预览不可用时明确视觉验证未完成。

## 渲染差异

- 有接缝或其他伪影时，对照源贴图、编辑器或目标运行时，区分预览器与工程问题。
- 参考女主的本次 MCP 预览可见脸部三角接缝，尚未完成原因定位，不应据此直接改脸部拓扑。
- 工具报告成功或 `renderer="spine-runtime"` 不能单独证明美术效果通过验收；查看实际产物并记录尚存问题。

## 交付资源

- 按需求交付 `.spine`、预览或运行时数据，列出实际工程、动画名和输出路径。
- 需要运行时资源时，重新调用 `spine_export_animation(format="json"|"binary")`；动画编辑不会自动更新旧 `.skel`。
- 核对目标运行时版本、纹理名、atlas 页面及所有页面图片。没有改贴图或 region 时可复用已核对图集；发生变化时再重新打包。
- `spine_pack_atlas` 的输出目录必须不存在或为空。打包参数按目标运行时核对 PMA、旋转、裁边和多页需求，不把默认值作为项目约定。
- GIF 可用 `spine_export_video`，精灵表可用 `spine_export_sheet`；MP4/WebM 需要服务端 ffmpeg。

## 失败与恢复

先检查具体错误、原文件是否保留、备份路径及是否发生外部保存冲突。JSON 重建只承诺可导出数据，编辑器文件夹、视图等专有信息由原始备份恢复。

`spine_rollback({projectPath})` 只列出备份；传 `backupId` 才执行恢复。备份数量有限，恢复前核对目标版本和后续有效修改，不把回滚作为盲目重试步骤。
