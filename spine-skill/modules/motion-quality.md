# 防穿帮与动作优化

配合 [动画制作](animation.md)、[骨架绑定](rigging.md) 和 [预览交付](delivery.md) 按需使用。目标是让素材、绑定和动作在要求的活动范围内共同成立；这是代理组织的检查与修复流程，不是 MCP 已提供逐像素自动检测、碰撞求解或图像生成。

## 先定位原因

先保留原动作和贴图，在工作副本或新动画名下修改。选取 setup、主姿势、关节最大弯曲、前后层次交换、换图前后和循环接缝，查看纯画面及必要的线框；均匀采样可能漏掉短暂穿帮，已发现问题的准确时间及邻帧要单独检查。

| 画面现象 | 检查与修复方向 |
| --- | --- |
| 肩颈、腋下、肘膝或腰部露出透明缺口 | 隔离源 PNG，缺像素则补绘；像素完整时检查搭接、枢轴与权重 |
| 关节塌陷、橡皮拉伸、纹理折叠 | 检查网格密度、三角形、影响骨骼和权重过渡，必要时局部 FFD 保体积 |
| 手臂穿身、裙片穿腿、发束前后关系错误 | 检查姿势、draw order、slot 划分和 clipping，按需要调整轨迹、换层或拆前后片 |
| 弯曲肢体、侧脸或手势无法保持原轮廓 | 制作动作专用附件并安排换图，不持续拉伸正面贴图硬撑透视 |
| 全身同步摇摆、起落匀速、脚底滑动 | 调整主姿势、支撑和时间间距，再分配头部与衣发的滞后和恢复 |
| 换图或循环瞬间跳动 | 检查锚点、比例、切换时刻、离散轨道和首尾速度，不能只把两端骨骼数值设为相同 |

已确认的缺画交给素材流程，绑定或时间轴错误在 Spine 内处理；不因预览器伪影直接重画角色。发现问题后先对照源图与编辑器或目标运行时，区分渲染差异。

## 手部与接触专项

手部动作或用户指出手部穿帮时，分别沿“前臂—腕—掌—指—接触物”检查两只手。先定位准确时间和实际附件，使用最新贴图，查看局部放大画面和正常尺寸播放，不只追踪腕点、指尖或握点。

- **手形与中间姿势**：手指长度、掌宽、拇指方向、弯曲和指缝应符合当前视角；不能出现多指、残指、手掌塌成块、指头粘连或翻折。遮挡允许部分手指不可见，不为凑齐五指而重画。重点查看收拢/展开、翻腕、回抱和接触进入/离开，不能只审查张开手与起止姿势。
- **腕口与素材残留**：手掌与前臂应连续，腕部转向和宽度一致；袖口/护腕遮住手腕的关系合理，不能出现断腕、透明缝、穿袖、皮肤钻出、旧手残影或原衣料白边粘在手上。隔离 PNG 与合成画面对照，区分切图残像、缺画、枢轴、形变和层级问题。
- **抓握与触碰**：抓握需看掌和手指是否实际包住物体、物体应穿过的指间关系及手背方向；触碰需看指腹/指尖的画面接触和正确前后关系，不能悬空、穿透、贴错帽面或擦过脸部。持物手随物体运动也必须保持腕部连贯，不能只把手与道具绑在同一骨骼便判通过。
- **形变与替换**：把张开的手沿单轴压扁，或只保留同一附件，不能代替可信的收手动作。FFD 改变了指骨结构、掌宽或厚度时，改用有依据的闭合/过渡手势素材或调整绑定；换图核对腕锚点、比例、轮廓、遮挡及前后邻帧，叠化也要检查重影。

记录问题时间、手的归属、附件及局部证据；修复后复查原处、邻帧和整段抬手/触碰/收手过程。手部仍有明显缺陷时判该版本不通过，其他关节修复或接触数值通过不能抵消。

## 与补图流程协作

1. 记录工程、动画名、问题时间（帧号附 FPS）、skin/slot/attachment、图片路径、截图及预期轮廓。附上旧 PNG 画布、附件变换与是否已有 mesh/FFD，使补图能保留原位与绑定。
2. 使用 Photoshop 技能的 [Spine 自动补图](../../photoshop-skill/modules/spine-image-repair.md) 恢复源像素、补关节或制作替换件。没有该技能时，仍可定位并交付上述素材修复信息；只有实际可用的图像编辑流程才能执行像素补绘，不能将 MCP 变形工具或初始摆位 JSON 当作补图。
3. 回接采用的实际 PNG、坐标清单及补图记录。先检查旧画布、锚点、附件路径、setup 外形和 UV 是否兼容，再更新工作副本。新替换件加入正确 slot 与动画轨道，不意外改动其他 skin 或动作；拓扑变化时保护已有 FFD。
4. 从当前贴图重新打包受影响图集，保存、回读并导出新快照；不使用旧 atlas 判断新贴图效果。对问题时间、邻帧和整段动作复验，再检查受共用贴图、权重或 setup 影响的其他动画。

补图或图像工具不可用时继续完成可独立进行的绑定和动作优化，明确缺画与视觉待验证项。用户只要求诊断时交付方案；已要求补图、防穿帮或优化效果时执行范围内的实际修复，无需逐张再次询问。缺少依据的新视角不能作为原稿真实设计，先使用已知设计完成可确定区域，记录其余待确认项。

## 减少生硬感

- 主姿势先确定动作线、剪影、重心和支撑，再调整关键姿势间的运动路径与帧间距。手脚沿符合关节的弧线运动；走跑支撑期用脚目标与身体位移配合，结合实际移动速度检查滑步。
- 节奏围绕动作意图组织蓄力、发力、接触、缓冲和恢复，不平均分配所有阶段。缓入缓出用于适合的段落；发力、冲击和刻意停顿保留所需的迅速或离散变化，不全局套同一曲线。
- 按动力关系安排骨盆、躯干、肩颈、头部，再补手臂与末端；跟随的相位和幅度由角色、材质与动作决定，不给所有骨骼统一正弦摆动。固定点稳定，过冲后有适度回收，末端不无故持续抖动。
- 弯曲处优先用合理权重保体积，必要时局部 FFD 或换图；别用无限加关键帧、增加网格或补绘来代替原因修复。脸部细节、袖根和发根等稳定区域设置合适固定点。
- 衣发跟随只在主体动作成立后添加。`spine_cloth_motion` 不提供碰撞，烘焙后逐段检查穿插；从同一基线调参，避免重复累加。表情、眨眼、呼吸按性格和节奏添加，不机械同步。
- 循环检查两侧的速度趋势、附件、FFD、IK 与层次；还要检查实际要用的动作切换和混合窗口。不同拓扑的附件换图不能假定靠动画 mix 自动连续，需选择相近轮廓时刻或增加合适的过渡附件。

## 修复闭环与结果

按“问题定位 → 最小原因修复 → 保存回读/更新预览资源 → 同帧和邻帧复验 → 整段播放及受影响动作复查”迭代。每项保留修复前后证据，记录已验证的动作范围与剩余问题，不用静态 setup 合成代替运动验收。

连续尝试无改善时换修复方向，保留可用版本并说明限制；不反复生成或烘焙直至耗尽资源。最终仍按预览交付模块判断通过、不通过或待验证；没有连续播放证据时不能宣称动画自然流畅。
