# 骨架装配与绑定

先读取 [工程通用](project.md)。已有可用 `.spine` 绑定时优先复用，只有任务需要时才重装配或重绑。

## 从贴图装配

- 一张透明 PNG 中的互不重叠散件，先用 `spine_cut_parts` 得到部件、蒙太奇和 `partsMeta.json`；查看后明确语义、父级和前后层次，再用 `spine_assemble` 的索引装配。
- 独立 PNG 目录使用 `spine_build_skeleton`。当前工具自动读取 `partsDir/partsIndex.json`，没有 `partsIndexPath` 参数；该索引格式不同于 assemble。生成骨骼默认都挂在 root 下，仍需整理层级与枢轴。
- 空工程从 `spine_create_project` 起步，再添加骨骼、插槽和附件。`spine_pipeline` 只在输入满足要求且需要预设动作全流程时使用。
- 完整人物立绘中被遮挡的肢体不能靠连通域自动补出；缺少拆件时明确所缺素材。任务包含补图、防穿帮或质量优化时，按 [防穿帮与动作优化](motion-quality.md) 接入素材补绘，得到实际 PNG 后继续装配。

精确索引格式见 [操作工作流](../references/mcp-workflows.md) 的“从拆分贴图建工程”。

## 层级、枢轴与附件

从单张完整图片制作动画时，先完成 [整图拆件](../../photoshop-skill/modules/image-part-split.md) 并检查真实部件、原位重建和遮挡补全，再开始绑定。完整角色图不能直接作为单个动画附件；整图加多骨骼权重或 FFD 也不满足拆图要求。已经拆出的各部件再按需要使用 region、mesh 和权重。

来自 See-through 等模型的语义分层，先经 [Photoshop 拆件流程](../../photoshop-skill/modules/image-part-split.md) 校正尺寸、补全和层序，再映射到骨架。同一语义层可能需要多个运动部件，多个颜色/线稿层也可能属于同一个部件；不以模型类别数决定骨骼数。深度估计只作初始 draw order 线索，动作中的前后交换仍需实际检查。

1. 从关节位置和预期运动关系确定骨骼父子与枢轴，结合插槽绑定确认左右和部件职责，不凭名称数字猜配对。
2. `spine_add_bone` / `spine_set_bone` 操作 setup 骨骼；`spine_add_slot`、`spine_add_attachment` 和附件变换工具负责挂接与拼接。调整 setup 会影响所有动画，不能用它代替某个动作的关键帧。
3. 骨骼坐标按父级空间处理，附件还有自身变换。修改父级或枢轴后重新检查世界外形，不只比较局部坐标。
4. 在 setup 中检查部件位置、缩放、透明边、层次和资源路径，再建立权重及约束。皮肤或附件改名优先使用同步引用的专用工具。

沿用女主工程时参考 [骨骼与插槽映射](../references/main-girl.md)，不要将普通命名的特殊肢体资源当作冗余数据删除。

## 网格与权重

- region 转网格可用 `spine_generate_mesh` / `spine_manage_attachment(convert_to_mesh)`；修改现有拓扑用 `spine_edit_mesh`。保留贴图路径和 setup 外形，先确认任务确需替换原拓扑。
- 用 `spine_get_mesh` 读取逻辑顶点、世界位置、三角形和逐点权重。加权网格的 `vertices` 存储骨骼影响项，不能用数组长度除以 2 当逻辑顶点数。
- `spine_edit_weights` 用于绑定、设置、归一化、剪枝和平滑；选择真实影响区域，修改后确认 setup 外形与动画跟随均符合预期。
- 自动权重用 `spine_auto_weights`，需要服务端已安装 libigl BBW 求解器。缺少时报告该条件，不将普通归一化称为自动绑定。参与骨骼与固定点依据实际几何选择。
- 先保留现有网格拓扑和权重。已有 FFD 时不要为了消除报错直接使用 `deformPolicy="clear"`，它会清除该附件在全部动画中的形变；关联/链接网格还有额外限制。确需改变时先在工作副本处理，并安排恢复受影响 FFD。

参数与限制见 [操作工作流](../references/mcp-workflows.md) 的“网格、权重与衣料”。

## 刚性末端与伸缩运动链

蹄壳、靴底、工具等需要保形时，先划定完整可见刚性区域与可弯曲接合区。脚点位置正确并不代表整件形状正确；检查实际世界变换、权重混合与 FFD，避免上段伸缩、非均匀缩放或切变传到刚性末端。

- 若脚底轨迹和刚性部件朝向已确定，可从源稿的接合点反求膝/腕连接，再由上段或适当的 IK 链完成连接；不能让不可靠的视频表面点强迫小腿变长、蹄部变薄。是否使用此方案由关节结构与目标轮廓决定。
- 可采用单骨骼权重、合适的变换继承或独立控制保持刚性，不统一要求挂到 root。即使端点帧抵消了父级缩放/切变，也要从实际运行时采样中间时刻；变换分解和各通道插值可能使抵消在帧间失效。检查可见区域内部距离/轮廓，按 [形状保持检查](motion-quality.md#局部形状与体积保持) 复验。
- 只有某个动画需要不同控制时，可在原 slot 新增复用同一纹理/UV 的动作专用附件，在该动画选择它，保留其他动画的原附件和轨道。附件改名后显式核对纹理 `path`，避免默认查找新名字而丢图；相同纹理和 region 未变时无需为新增附件重复打图集。
- 独立末端控制仍须保持根部/接合轮廓随身体连接，不能只消除缩放就接受悬空或滑动。先逐件隔离，再恢复近远部件与身体遮挡检查整段运动。

## 连续连接处的绑定

单图拆出的茎与叶、秆与穗、发根与发束或相邻衣片，在 setup 中贴合后还需检查动态连接。先区分真实连接边、遮挡重叠边与独立外轮廓，按各自结构决定约束和活动范围。

- 在源图统一坐标中定位连接根部、切线及其两侧的实际像素，检查父骨骼、附件变换、权重、FFD 和局部相位对这些位置的共同作用。同一父级或重合枢轴只能提供部分依据，验收对象是变形后的接合轮廓。
- 需要连续的切口两侧保持一致的世界运动。按结构选择共用控制骨骼、接合区匹配的权重或约束，独立旋转与滞后从接合区向自由末端逐渐增加。长而柔软的叶片、发束或衣片可用局部网格过渡，同时检查体积、弯曲方向与运动传递。
- 两片网格共用变形场时，在统一源坐标下检查边界采样与三角插值是否一致。共用采样位置是可选实现，网格密度按有效轮廓、曲率和实际显示尺寸确定。保留真实拆件与各自附件关系。
- 活动后确实露出的底层和根部按 Photoshop 流程补齐。接合两侧位移不一致时先修绑定，再按目标极值测量仍需补足的像素搭接。

正式制作附属摆动前，按 [切口连接专项](motion-quality.md#切口连接专项) 检查接合区及其邻近轮廓。

## 约束与验收

- 根据运动需求选择 IK 或 FK，目标骨骼与受约束链分开定位；沿用工程时先检查现有约束的目标、顺序和 mix。
- 接触目标用 IK 时同时安排手掌/脚掌朝向，检查可达范围、弯曲分支、继承变换和混合；FK 同样检查末端弧线。柔软连续表面用网格时保持关节体积，刚性或自然分节部件按转轴控制；大幅掌面/视角变化使用替换附件。工具选择服从画面需要，不能从一次 FK 修复成功推导所有动作都不用 IK。
- 已受 IK 驱动的腿优先调整脚部目标和身体控制器；需要 FK 时明确安排 IK mix，避免大腿旋转被约束覆盖。不要把 IK 目标映射成大腿模板角色。
- 绑定后检查 setup、关节弯曲和代表性极限姿势。既有工程还要抽查受影响动作，留意塌陷、拉伸、部件漂移和穿插。
- 极限姿态露底先分辨缺画、搭接、枢轴、权重或绘制顺序；按 [防穿帮与动作优化](motion-quality.md) 修复并复验，不单靠缩小转角掩盖缺陷。
- 按工程通用模块完成保存与引用检查，再按 [预览交付](delivery.md) 检查线框和纯画面。只有初始摆位 JSON 时，不能声称已完成权重绑定。
