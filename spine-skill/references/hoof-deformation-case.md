# 马蹄变形：轨迹正确仍会穿帮

用于蹄/靴/道具被压薄、视频复刻出现假关节，或用户指出数值通过但画面变形时。它是一次真实失败的诊断记录，不是已验收质量样本，也不规定所有角色使用相同绑定或容差。

## 现象和原因

2026-11-11，行商马车 `video_walk` 的三秒循环中，近前腿抬蹄时白色蹄毛挤成薄片，棕色蹄壳与膝部轮廓异常。用户指出穿帮后，原有新动画外形及整体通过结论被撤回。

| 环节 | 发生的问题 | 后续判断 |
| --- | --- | --- |
| 预演 | 用简化关节代理获得方向确认，画面没有呈现真实蹄毛与接合 | 不能据此证明实际贴图的最终效果；按当前流程先完成最终效果帧再验收 |
| 视频提取 | 皮肤上的跟踪点被当作膝部枢轴；远侧遮挡段也只能推定 | 核对真实接合与轨迹归属，错误点不能驱动末端变形 |
| 运动链 | 为追膝/脚目标而让上下腿伸缩、剪切，再用 FFD 保靴形 | 蹄点匹配但白色蹄毛仍遭压缩；先修关节/变换关系 |
| 初次保形修正 | 在父子链中补偿末端变换 | 关键帧基本恢复，中间时刻仍有小幅形变；按实际运行时插值复验 |
| 验收 | 零网格翻面、脚点误差小、循环首尾一致被误当作无穿帮 | 这些指标均不证明局部轮廓、体积和接合；需要分开检查 |

## 本例实际修复

按参考脚底轨迹和部件朝向确定完整小腿/蹄件的刚性变换，从源稿接合点反求膝部连接，由上腿承担弯曲。为这个动作新增四个独立蹄部控制，以及原 slot 中复用原 PNG/UV 的四个动作专用附件；单骨骼权重，取消这些新附件的压缩 FFD。原 39 骨骼、46 slot、原附件及其他三个动画保留；当前共 43 骨骼、50 附件定义，车轮层序不变。

此结构适合本例已有完整小腿素材和活动范围；其他角色可用不同继承、约束、权重或替换件，按目标轮廓判断。独立控制没有自动保证关节连接正确，仍需完整构图复查。

## 证据与边界

保存回读后的官方 Spine 3.8 运行时中，按实际纹理覆盖选择四个蹄/蹄毛区域，分别检查 99、108、106、112 个可见三角形，各采样 181 个时刻。修复前边长变化最差约 55%，近前区域部分三角形面积最小约为原来的 19%，但没有翻面。修复后本区域边长变化最大约 0.00093%，面积比约 0.99999–1.00001。以上是本例测量结果，不能作为通用阈值。

画面检查分别隔离四腿，再在完整构图核对 0.33 秒抬前蹄、0.37 秒邻帧、0.50 秒抬后腿、0.67 秒落点，并正常速度播放；JSON 和二进制分别更新并回读。证据保存在该任务的 `metadata/hoof-shape-verification.json`、`metadata/hoof-fix-build-report.json` 和 `previews/video-match/hoof-fix-review.png`。
