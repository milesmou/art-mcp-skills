# 动作制作配方

配合 [动画制作](../modules/animation.md) 的分阶段流程使用，只读本次动作对应部分。以下是姿势设计与检查步骤，不是固定参数模板或已经验收的优质案例。时间、幅度、曲线和跟随关系由角色风格、动作意图、素材活动范围和实际显示尺寸决定；不要把各阶段平均分配，也不要统一套正弦或缓入缓出。

已有人工案例与适用范围见 [已验收工程标准](accepted-production-standard.md)。例如书生的普通、焦急、生气待机分别采用持扇、扶头、握拳等状态姿势；同类情绪待机先改变身体与手势设计，再安排小幅循环，不只修改呼吸速度。项目中的八种顾客动作是该用途的基线，不扩展单动作任务的范围。

## 待机 idle

1. **选择任务类型与参考。** 区分常驻基础循环、情绪状态循环和偶发待机小动作。参照 [已验收动作索引](../../spine-animation-director/references/accepted-motion-library.md) 查看实际片段：女主 `idle` 与 `idle_act_*` 分开，书生/混混各状态有不同手势与脸，农夫普通 idle 有抚须。用户只要一段时不自动扩成整套；不从名字推定为呼吸或长篇事件串。
2. **建立状态姿势。** 从放松、警戒、疲惫等具体状态出发，确定视线、支撑腿、重心、手势与道具接触。原立绘不强制成为所有动画的姿势；需要的弯臂、手掌或袖型应列入切图/替换件。双脚站稳和悬浮角色采用各自支撑逻辑，不强制所有角色左右换重心。
3. **设计主体变化。** 在成立的姿势中选择可读的主要行为，如持扇的身体韵律、抚须往返、警戒承重或疲惫下沉。选起始、行为极值、经过与恢复姿势；呼吸仅在符合状态时作为主要或辅助变化。相同显示高度比较匹配参考的胸肩、骨盆、头、肘手、道具及脚，不用整图平移缩放代替。
4. **安排节奏。** 参照匹配片段周期与动作先后，明确发起、停留、回落。偶发动作按需独立交付并约定返回基础 idle；不能每次基础循环都重复长串调武器、观察等事件，也不由参考动画名编造游戏触发逻辑。保持握持和脚底关系，不规定所有状态使用同一时长或吸呼比例。
5. **补局部表现。** 根据主体驱动补肩颈、头部跟随及衣发恢复，眨眼按状态安排，避免与胸肩和衣发机械地同相往复。刚性武器保持轮廓与握点；t=0 建立状态的附件选择与循环中途换图分别处理。
6. **检查。** 正常速度、实际显示大小下看得出角色状态和约定主行为；与匹配已验收参考并排看姿势、节拍与幅度，不将安静参考或夸张参考泛化到所有角色。连续看循环接缝及两侧速度，偶发动作检查返回与状态恢复。脚底、握点、面部和关节不漂移或破坏。

过弱时先比较峰值与起始的姿势差异、运动方向和停留，再调整主要变化；全身同步摇摆时重新分配主动与跟随部位。不要等比放大所有轨道，也不要为了“动得多”让脚底和武器失稳。

## 攻击 attack

1. **定义攻击行为。** 明确攻击方向、目标位置、武器或肢体的接触点、支撑脚及结束后要衔接的动作。若游戏规定命中时刻、前摇或后摇，以约定为准；缺少战斗参数时按演示动作设计并记录假设，不宣称事件已适配游戏。
2. **摆主体姿势。** 设计预备、发力、接触、跟随和恢复姿势，检查攻击轨迹与剪影。预备应服务于攻击方向，接触时武器/手脚和身体发力关系明确；跟随让动作有惯性，恢复回到可继续行动的姿势。快速刺击可以压缩预备与跟随，不强制大幅蓄力。
3. **安排时间与路径。** 根据意图区分蓄力、加速、接触和减速；通常发力比准备或恢复更迅速，但不固定比例。手脚或武器末端路径应连贯，逐查接触及邻帧，避免插值绕远路、肢体翻转或一帧穿身。接触停顿仅在设计需要时加入。
4. **补跟随与形变。** 主体力度成立后再补头部、衣发与末端回收。武器保持刚性，双手握持检查两只手与握点；无法用现有视角成立的手势或肢体用动作专用附件，不硬拉正面贴图。
5. **检查。** 暂无特效时仍能看出攻击方向与接触时刻；脚底和重心支撑可信，接触后有适当缓冲或跟随。检查结束及回待机的过渡，若交付包含游戏事件，则再验证命中事件与可见接触一致。

像挥手或没有力度时先修躯干参与、接触姿势、发力路径及时间对比；不要只加大手臂角度、提高全段播放速度或添加拖尾。攻击过慢时定位拖沓阶段，不把全部时长等比压缩。

## 走路与跑步 walk / run

1. **确定移动方式。** 明确方向、步态、循环周期、原地动画或根位移，以及预期场景速度。没有场景速度时先验证步态，记录地面接触验证的限制，不声称已消除游戏内滑步。
2. **设计支撑与关键姿势。** 走路围绕接触、承重、经过、抬升及另一侧接触摆姿势；常规走路保留支撑及双支撑过渡。跑步围绕接触、压缩、蹬伸和腾空设计，按目标风格确认是否存在腾空段。不要将走路简单加速当作跑步。
3. **制作下肢与骨盆。** 先配合脚部目标、身体移动与骨盆起伏，再调膝部和抬脚弧线。支撑期脚相对地面稳定，摆动期有适当离地高度；原地动画的脚相对身体向后移动应与场景前进速度匹配，不把局部脚坐标恒定当作不滑步。根位移动画检查世界空间接触，避免运行时重复叠加位移。
4. **补上身和附属运动。** 下肢成立后设计躯干、肩部、手臂及头部的配合，持械角色优先保证握持。最后补衣发滞后和回弹，不能用上身大摆动掩盖承重不足。
5. **检查。** 在匹配速度的地面参照下播放，分别检查左右接触、承重、离地和循环接缝；支撑脚无非预期滑动，膝部不翻转，落地有承重。非对称角色不强制两侧镜像；需要游戏交付时再验证起停与动作混合。

漂浮时先修接触、承重和骨盆路径；滑步时先核对步幅、周期、场景速度和脚轨迹；腿部抽动时先检查 IK 目标、链方向和路径。不要只增加脚部关键帧或扩大身体上下振幅。

## 其他动作

受击、跳跃、施法等沿用同一阶段流程，按动作意图列出必要姿势、接触或支撑变化、关键时刻及恢复目标。不存在的阶段可以省略，主动表现必须保留；不把攻击的发力结构或待机的呼吸循环强套到所有动作。
