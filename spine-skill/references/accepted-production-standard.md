## 制作标准

1. **从动作集合设计素材和绑定。** 根据任务列出基础姿态、情绪状态、移动、单次表现及保持动作；确定支撑、握持、前后交换和所需替换件。沿用工程时完整继承附件、约束、FFD、层次等相关通道，不只复制骨骼旋转。
2. **先做角色成立的主姿势。** 在预期使用尺寸下确认轮廓、视线、手势与重心。待机允许克制，角色状态清楚、局部变化有目的即可；小满的托腮姿势、书生的持扇姿势说明身份与姿势本身就是表现，不需为了“明显在动”持续扭动全身。
3. **把接触关系做成稳定约束。** 脚与地面、手与道具、手与脸部等按需要建立控制关系，躯干带动时接触不漂移。女主的身体主控与脚部 IK、农夫的脚部目标和锄头、歌姬与琵琶分别提供不同场景的参考；不据此强制统一骨架。
4. **把主体节奏与附属材质分开调整。** 先通过 [分阶段制作](../modules/animation.md#分阶段制作与推进条件) 的主姿势和主体运动检查，再补发束、袖口、胡须、裙片与饰物。根部稳定，末端随动作有原因地延迟、回弹或保持；刚性道具不套布料形变。
5. **用替换件承担视角和轮廓变化。** 伸手、握拳、手贴脸、弯曲肢体及不同袖型必要时采用专用附件；同步检查换图锚点、可见性、FFD 和绘制顺序。女主跳起时的腿、书生的手臂与袖子是明确案例。
6. **按实际使用设计结束和状态恢复。** 明确单次结束、持续保持、回待机或另接 loop。动画结束后不得意外残留嘴型、手势、特效或层次；需要混合时在对应运行时检查，不仅对齐两端数字。

对应动作设计步骤继续使用 [动作配方](action-recipes.md)。该目录并不能证明所有类型的攻击、跳跃等都有现成优质参考；选择参考时先确认实际动作语义，不仅匹配名字。

## 验收标准

先选择同体型、同用途、同情绪的已通过参考，记录工程相对路径、源版本或哈希、动画名和对照片段。新作与参考应在相同角色显示高度、固定取景和正常速度下比较；需要时再慢放或放大。对比的是状态表达、姿势、节奏、接触及画面完整度，不能只比较摆动幅度。

| 验收项 | 通过标准与观察方法 | 应退回修正的表现 |
| --- | --- | --- |
| 角色与状态 | 脸、比例、服装和道具保持原设计；普通、焦急、生气等状态符合需求，有明确姿势或表情依据 | 表情与身体意图冲突，状态只靠名字区分；精修后改变角色辨识度 |
| 主姿势 | 实际尺寸下剪影、手势、视线与重心成立；不靠特效遮掩主体缺陷 | 肢体相互遮掉关键手势，持物姿势不成立，失去支撑却没有相应运动 |
| 节奏与力度 | 连续播放能看清意图、主要变化及收势；有意的保持、夸张和小幅变化按风格判断 | 全段机械同步、无意停顿或抽动，动作力度与状态不符 |
| 接触与运动路径 | 握点稳定，肢体沿合理路径变化；走跑在约定场景速度下检查支撑脚 | 手脱离道具、道具软化、明显滑步或抬脚穿地；未测场景速度却宣称无滑步 |
| 形变与遮挡 | 同时检查纯画面、关节极限、表情变化和前后交换，维持体积、纹理与轮廓 | 脸部拉坏、关节露底、袖口断开、穿插、双手或双腿重复显示 |
| 附属运动 | 发根、袖根与固定点稳定，软硬材质区分明确，不抢走主动作 | 全身同相摆动，末端无故抖动、穿身或反向跳变 |
| 循环与衔接 | 仅对需要循环的动作检查接缝及两侧速度；单次动作检查结束与约定衔接，覆盖附件、FFD、约束及层次 | 循环顿挫、切换跳姿、结束后残留错误资源；不能仅因首尾数值不同否决已验收参考 |
| 工程与交付 | 最新工程保存回读、路径引用和导出资源正确；按任务范围验证游戏版本、事件、混合及性能 | 交付旧快照、缺图、版本不兼容、约定动作或附件缺失 |

有影响使用的破图、状态错误、接触失败或衔接问题，应修正后复查，不用其他表现项抵消。尚未查看连续播放、目标场景或混合的检查项，分别标记待验证，不能用静态联系表替代。无需把本次参考总结变成对既有合格工程的重新判分。

建议每次交付用简短记录保留：`参考版本/动作 → 新作版本/动作 → 查看尺寸与速度 → 主姿势/连续播放/接触/形变/衔接结论 → 具体问题时间与修正证据`。最终判定继续遵循 [预览交付](../modules/delivery.md#验收结论)。
